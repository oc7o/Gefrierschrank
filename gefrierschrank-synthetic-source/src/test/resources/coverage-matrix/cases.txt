# End-to-end coverage matrix (ReconstructionCoverageTest). Each case: the mapping (the test adds
# "_source":{"enabled":false}), extra settings, the expectation, and documents. Expectations:
#   covered                 every document equals the native-synthetic oracle, or differs only in
#                           fields its _ignored lists and is counted
#   refused <tokens>        the open or the first read refuses with exactly these tokens
#   covered-unordered       covered, comparing arrays as sorted (synthetic_source_keep kept the sent
#                           order only in _ignored_source, which stored mode never wrote)
#   optin <paths>           with --source-disabled-accept unmapped-values: covered once the oracle
#                           drops these paths (values under dynamic:false/runtime objects)
# An "inject:" line adds to the stored-mode index a delete tombstone ("tombstone") or a Lucene
# field no mapper knows ("stray"), or ("delete <i>") commits before the last document, deletes
# document i (counted over doc: and update: lines) and force-merges into one segment after the last.
# An "update:" line between documents merges a mapping update into the stored-mode index.
# Every segment's FieldInfos leaf (the commit-point preflight) must refuse exactly as its real
# leaf; a "preflight:" line names what the FieldInfos leaf gives instead ("none" for nothing) where
# the real leaf refuses on data the preflight cannot see.
#   unbuildable             the isolated MapperService cannot build the mapping at all (no analysis
#                           modules, no script compiler): the worker fails at open, as in 1.1.0
# The real leaf with its _field_names postings hidden must refuse exactly as the real leaf; a
# "pruned:" line names what it gives instead where a text field without norms with a keyword
# multi-field has postings but no _field_names entry (fail closed, values without tokens unseen).
# Settings default to index.version.created=9039000 (ES 9.3).
